# Dashboard

Zona de trabajo de frontend: React, TypeScript, Vite, Recharts y Tailwind, según las dependencias que acuerde el equipo.

**Estado inicial:** carpeta preparada; aún no se ha publicado una aplicación React funcional aquí.

Debe visualizar claramente resultados observados, predicciones, tamaños muestrales, intervalos de confianza y procedencia de datos. La ausencia de tracking se comunica como **Seguimiento pendiente**.

La integración prevista es `GET /api/resumen`. Véase `docs/CONTRATO_API.md`.
