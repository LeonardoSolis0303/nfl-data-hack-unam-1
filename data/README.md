# Datos

Esta carpeta documenta las fuentes y los permisos de uso de los conjuntos de datos.

**No publiques aquí los CSV originales del concurso ni datos privados sin confirmar que está permitido redistribuirlos.** El `.gitignore` excluye por defecto los archivos CSV, Parquet y ZIP bajo `data/`.

Para reproducir un análisis, registra localmente el origen, la versión, las columnas, los filtros y las particiones (entrenamiento / validación / confirmación). En `docs/` puede almacenarse documentación sin datos sensibles.

Esta carpeta no contiene aún datos de entrada del modelo.
