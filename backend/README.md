# Backend

Zona de trabajo del integrante responsable de Python, análisis estadístico y API.

**Estado inicial:** carpeta preparada; todavía no hay implementación del servicio comprometida en este repositorio.

El endpoint propuesto para acordar entre ambos integrantes es `GET /api/resumen`.

No se deben devolver métricas precargadas como si hubieran sido calculadas desde un CSV. Si se necesita una respuesta de práctica, debe identificarse como `demo`.

Consultar `docs/CONTRATO_API.md` antes de implementar.
